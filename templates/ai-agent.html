Kairos는 사내 AI 에이전트의 배포·관찰·통제를 한 화면에서 처리하는 운영 플랫폼입니다.

고객사 로고 자리 · 실제 고객사 로고로 교체

1.0관찰

모든 실행을
단계별로 추적합니다

계획부터 응답까지, 에이전트가 거친 모든 단계가 밀리초 단위 트레이스로 남습니다. 어디서 느려졌는지, 토큰을 어디에 썼는지 실행이 끝나기 전에 보입니다.

  • 실시간 트레이스진행 중인 실행도 지금 어느 단계에 있는지 바로 확인합니다.
  • 토큰·비용 집계실행, 에이전트, 팀 단위로 토큰과 비용을 나눠 봅니다.
  • 실패 재현실패한 실행을 같은 입력과 도구 응답으로 다시 돌려 원인을 찾습니다.

2.0통제

위험한 행동은
승인 없이 나가지 않습니다

외부 메일 발송, 결제 API 호출, 개인정보 조회. 에이전트가 할 수 있는 일을 정책 한 줄로 정하고, 바꾸기 전에 영향받는 에이전트부터 확인하세요.

  • 권한 범위에이전트마다 쓸 수 있는 도구와 데이터를 나눕니다.
  • 승인 흐름금액, 수신 대상, 시간대 조건에 따라 담당자 승인을 받습니다.
  • 변경 영향 미리보기저장하기 전에 지난 7일 실행 기준으로 영향을 계산합니다.

3.0개선

바꾸기 전에,
숫자로 비교합니다

프롬프트나 모델을 바꾸면 같은 평가셋으로 기존 버전과 나란히 돌립니다. 정확도가 오르고 비용이 내려갔는지 확인한 뒤에 배포하세요.

  • 실제 사례로 만든 평가셋운영 중인 실행에서 고른 사례로 평가셋을 만들고 계속 늘립니다.
  • 회귀 감지한 지표라도 나빠지면 배포 전에 알려 줍니다.
