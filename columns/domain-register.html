홈페이지를 만들려면 주소, 즉 도메인이 필요하다는 얘기를 들으셨을 겁니다. 어렵게 느껴지지만 실제 등록 절차는 쇼핑몰에서 물건 사는 것과 크게 다르지 않습니다. 이 글에서 도메인 등록 절차와 초보자가 놓치기 쉬운 포인트를 정리해 드립니다.

도메인이 정확히 뭔가요

도메인은 인터넷에서 내 홈페이지를 찾아오는 주소입니다. 예를 들어 naver.com 같은 형태죠. 도메인은 구매가 아니라 연 단위 임대에 가깝습니다. 매년 등록비를 내고 사용권을 유지하는 방식입니다.

.com, .co.kr, .kr 등 끝부분(확장자)에 따라 가격이 다르며, 보통 연 1만~3만 원대입니다.

등록 절차는 네 단계

  1. 도메인 등록업체 사이트에 접속해 회원가입
  2. 원하는 도메인 이름을 검색해 사용 가능 여부 확인
  3. 등록 기간(1년~) 선택 후 결제
  4. 소유자 정보 확인 및 등록 완료

국내외에 여러 등록업체가 있고 기본 기능은 대동소이합니다. 가격, 관리 화면의 편리함, 고객 지원 언어 정도를 보고 고르면 됩니다.

이름 정할 때 확인할 것

도메인 이름은 짧고, 발음하면 철자가 떠오르는 것이 좋습니다. 전화로 불러줬을 때 상대가 바로 입력할 수 있는지 상상해 보세요. 하이픈이나 헷갈리는 숫자 조합은 피하는 편이 무난합니다.

상호와 같거나 비슷한 이름이 이미 등록돼 있다면 확장자를 바꾸거나(.kr 등) 지역명·업종명을 붙이는 방법이 있습니다.

등록할 때 주의할 점

가장 중요한 건 소유자 정보를 본인(또는 회사) 명의로 등록하는 것입니다. 제작사나 지인 명의로 등록하면 나중에 분쟁이나 이전 시 곤란해질 수 있습니다. 제작을 맡기더라도 도메인 계정은 직접 만들고 관리하는 것을 권합니다.

또 하나는 갱신입니다. 갱신을 놓치면 도메인이 만료돼 홈페이지와 이메일이 함께 멈춥니다. 자동 갱신을 켜두고 결제 카드 유효기간을 관리하세요.

정리

첫째, 도메인은 연 단위로 비용을 내는 홈페이지 주소이며 등록 절차는 검색과 결제로 끝납니다. 둘째, 소유자 명의는 반드시 본인으로 하세요. 셋째, 자동 갱신 설정으로 만료 사고를 예방하세요. 도메인을 홈페이지에 연결하는 과정이 어렵다면 제작사의 도움을 받으면 되는데, NOAH도 기본 패키지에 도메인 연결과 SSL 안내를 포함하고 있습니다.
