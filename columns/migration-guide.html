홈페이지 이전, 순서만 지키면 어렵지 않습니다

호스팅 비용이 부담되거나 제작사와의 관계가 끝나면 홈페이지 이전을 고민하게 됩니다. 이전 자체는 특별한 일이 아니지만 순서를 지키지 않으면 사이트가 며칠씩 먹통이 되거나 애써 쌓은 검색 순위를 잃을 수 있습니다. 옮겨야 할 것과 순서를 정리했습니다.

옮길 자산부터 목록으로 만드세요

  • 도메인: 등록기관 계정 접근 권한이 나에게 있는지가 출발점입니다.
  • 콘텐츠: 글, 이미지, 상품·서비스 정보, 고객 후기 등 사이트의 실제 내용.
  • 기능과 데이터: 예약·문의 내역, 회원 정보, 게시판 글 등.
  • SEO 자산: 기존 페이지 주소(URL) 목록, 검색 등록 상태, 외부에서 걸려 있는 링크.
  • 계정류: 호스팅, 관리자, 분석 도구 계정 정보.

순서는 새 집을 다 지은 뒤 이사입니다

핵심 원칙은 하나입니다. 기존 사이트를 내리기 전에 새 사이트를 완성하는 것. 새 서버에 사이트를 만들어 임시 주소로 충분히 테스트한 뒤 마지막에 도메인 연결(DNS)만 새 서버로 바꿉니다. 이 순서면 다운타임이 거의 없습니다. 반대로 기존 계약부터 해지하면 사이트가 내려간 채로 새 사이트를 급조하게 됩니다. 기존 호스팅은 이전 완료를 확인한 뒤에 해지하세요.

리다이렉트가 검색 자산을 지킵니다

페이지 주소가 하나라도 바뀐다면 옛 주소로 들어온 방문자와 검색엔진을 새 주소로 자동 안내하는 301 리다이렉트를 설정해야 합니다. 이것을 빠뜨리면 검색 결과와 외부 링크가 전부 없는 페이지로 이어지고 쌓아온 검색 순위도 흔들립니다. 주소 구조를 아예 바꾸는 이전이라면 옛 주소와 새 주소의 대응표를 만들어 제작사에 전달하세요.

이전 후 일주일은 점검 기간입니다

DNS 변경은 전 세계에 반영되기까지 시간이 걸리므로 변경 직후 일부 방문자는 옛 서버를 볼 수 있습니다. 반영이 끝나면 주요 페이지 접속, 문의·전화 버튼, 모바일 화면, 폼 제출을 하나씩 확인하세요. 서치콘솔 같은 검색 도구에 새 사이트맵을 제출하고 옛 주소 몇 개를 직접 입력해 리다이렉트가 작동하는지도 확인하면 마무리입니다.

이사의 순서를 지키세요

도메인과 콘텐츠, 데이터, SEO 자산을 목록으로 만드는 것이 이전의 시작입니다. 새 사이트를 완성해 테스트한 뒤 도메인만 돌리면 다운타임은 막습니다. 301 리다이렉트는 검색 자산을 지키는 열쇠이니 빠뜨리지 마세요. 이전을 계기로 아예 새로 만드는 것도 방법입니다. NOAH는 7일 안에 반응형 홈페이지를 오픈하므로 기존 사이트를 유지한 채 갈아탈 새 집을 빠르게 준비할 수 있습니다.
