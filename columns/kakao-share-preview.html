카카오톡 공유 미리보기가 안 바뀔 때 — 이미지·제목 고치는 순서

홈페이지를 고쳤는데 카카오톡으로 링크를 보내면 예전 이미지와 제목이 나올 때 확인할 순서를 정리했습니다. 공유 디버거 캐시 초기화와 이미지 주소 바꾸기까지.

2026.10.30 ·약 4분 ·NOAH 편집팀

홈페이지를 고쳤는데 카카오톡 공유 미리보기가 예전 그대로예요. 어떻게 바꾸나요?

카카오가 미리보기를 저장해 두기 때문입니다. 카카오 개발자 사이트의 공유 디버거에서 캐시를 초기화하고, 이미지는 파일 이름을 바꾸거나 주소 뒤에 ?v=2를 붙여야 새로 반영됩니다.

  1. 미리보기는 어디서 오나
  2. 고치는 순서
  3. 처음부터 잘 만드는 기준
  4. 참고한 자료

카카오톡은 링크가 처음 공유될 때 페이지의 제목·설명·이미지를 읽어 저장해 두고, 그다음부터는 저장한 것을 보여 줍니다. 그래서 홈페이지를 고쳐도 미리보기가 그대로입니다. 공유 디버거로 저장된 정보를 지우고, 이미지는 주소 자체를 바꿔야 새로 반영됩니다.

미리보기는 어디서 오나

미리보기는 페이지 head에 있는 오픈그래프 태그에서 옵니다. og:title(제목), og:description(설명), og:image(이미지), og:url(대표 주소) 네 가지가 핵심입니다. 이 태그가 없으면 카카오톡이 페이지 본문에서 아무 글자나 이미지를 골라 보여 주기도 합니다.

고치는 순서

  1. 태그부터 확인 — 브라우저에서 페이지 소스 보기를 열어 og 태그가 새 내용으로 바뀌었는지 확인합니다. 여기서 예전 그대로면 카카오 문제가 아니라 홈페이지 수정이 덜 된 것입니다.
  2. 공유 디버거에서 캐시 초기화 — 카카오 개발자 사이트(developers.kakao.com)의 도구 메뉴에서 공유 디버거를 열고, 주소를 넣은 뒤 캐시 초기화를 누릅니다. 카카오 개발자 계정 로그인이 필요합니다.
  3. 이미지가 그대로면 이미지 주소 바꾸기 — 디버거는 제목·설명 같은 정보만 지우고, 이미지 썸네일은 이미지 주소 기준으로 따로 저장해 둡니다. 이미지 파일 이름을 바꾸거나(예: og.jpg → og-2026.jpg) 주소 뒤에 ?v=2를 붙이면 새로 만들어집니다.
  4. 내 휴대폰에서만 예전 그대로면 — 카카오톡 앱이 기기에 저장한 이미지일 수 있습니다. 카카오톡 설정에서 임시·캐시 데이터를 지운 뒤 다시 확인합니다.
  5. 주소 표기 맞추기 — http와 https, 주소 끝의 슬래시(/) 유무에 따라 캐시가 따로 잡힐 수 있습니다. 공유하는 주소를 한 가지로 통일하세요.

처음부터 잘 만드는 기준

항목권장
og:image가로:세로 2:1에 가까운 이미지(예: 800×400, 1200×630), JPG나 PNG, https로 시작하는 전체 주소
og:title상호와 핵심 한마디를 짧게 — 길면 잘립니다
og:description무엇을 하는 곳인지 한 문장
og:url실제 대표 주소와 똑같이

보안 플러그인이나 방화벽이 카카오의 수집 로봇을 막으면 미리보기 자체가 뜨지 않습니다. 이미지가 아예 안 나온다면 이 부분도 확인하세요.

노아홈페이지도 2026년 10월 대표 미리보기 이미지를 바꿀 때 예전 이미지가 남지 않도록 이미지 파일 이름 자체를 새로 바꿨습니다. 제작하는 홈페이지에는 카카오톡 미리보기 카드 설정이 기본으로 들어갑니다.

참고한 자료

  • 카카오 데브톡 — 스크랩(URL 미리보기) 안 될 때 체크리스트
  • 카카오 데브톡 — OG 이미지 변경이 안 됩니다
  • 카카오 데브톡 — URL 끝 슬래시에 따라 이전 OG 이미지 표시
