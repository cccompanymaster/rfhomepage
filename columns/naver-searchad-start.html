네이버 검색광고 처음 시작하는 순서 — 가입부터 첫 광고가 뜨기까지

네이버 검색광고를 처음 하는 사장님을 위해 가입·사업자 인증, 광고비 충전, 캠페인·광고그룹·키워드·소재 만들기, 검토까지 순서대로 정리했습니다. 처음에 자주 하는 실수도 함께 담았습니다.

네이버 검색광고는 어떤 순서로 시작하나요?

검색광고 가입과 사업자 인증 → 광고비 충전 → 캠페인 → 광고그룹 → 키워드·광고 문구 등록 → 검토 순서입니다. 검토에는 보통 1~2일이 걸려서 오늘 만들어도 바로 뜨지는 않습니다.

네이버 검색광고는 가입과 사업자 인증 → 광고비 충전 → 캠페인 → 광고그룹 → 키워드와 광고 문구 → 검토 순서로 시작합니다. 마지막 검토에 보통 1~2일이 걸리기 때문에, 행사나 오픈에 맞춰 광고를 띄우려면 적어도 며칠 앞서 만들어 두는 게 좋습니다.

1. 가입과 사업자 인증

네이버 검색광고에 광고주로 가입하고 사업자 정보를 인증합니다. 사업자로 등록할 때 사업자등록증을 첨부하라는 안내가 있으니 파일을 미리 준비해 두세요. 광고할 홈페이지 주소도 이 단계 전후로 등록하게 되는데, 홈페이지도 검토를 거치므로 내용이 다 갖춰진 상태에서 등록하는 편이 좋습니다.

2. 광고비 충전

검색광고 광고비는 미리 충전해 두고 쓰는 방식이며, 신용카드나 현금으로 충전할 수 있다고 안내됩니다. 충전금이 없으면 검토와 노출이 늦어지는 경우가 많다는 설명이 여러 곳에 있으니, 광고를 만들기 전에 소액이라도 넣어 두세요.

3. 캠페인 → 광고그룹 → 키워드·광고 문구

단계무엇을 정하나처음 할 때 팁
캠페인광고 유형(검색 결과에 뜨는 파워링크 등), 이름, 예산하루 예산 칸에 한 달 예산을 넣는 실수가 흔합니다. 그러면 하루 만에 다 써 버립니다
광고그룹같은 주제의 키워드를 묶는 단위. 도착할 페이지 주소, 기본 입찰가'커트', '염색'처럼 손님이 찾는 서비스별로 나누면 관리하기 쉽습니다
키워드광고를 띄울 검색어넓은 말보다 지역·서비스가 들어간 구체적인 검색어부터
광고 문구(소재)검색 결과에 보일 제목과 설명키워드와 같은 말을 쓰고, 도착 페이지에 실제로 있는 내용만

입찰가는 여러 안내 자료 기준 최소 70원부터 정할 수 있습니다. 입찰가와 품질지수가 순위와 비용에 어떻게 작용하는지는 파워링크 비용 칼럼에서 따로 설명했습니다.

4. 검토를 기다리는 동안

광고 문구와 키워드, 도착 페이지까지 광고의 모든 구성 요소가 검토 대상입니다. 기다리는 1~2일 동안 할 일은 광고가 데려올 손님을 맞을 준비입니다.

  • 도착 페이지 첫 화면에 가격·예약 방법·전화 버튼이 보이는지 휴대폰으로 확인
  • 광고 문구에서 약속한 내용(이벤트 가격 등)이 페이지에 그대로 있는지
  • 광고로 들어온 방문을 따로 볼 수 있게 분석 도구 연결 — 구글 애널리틱스 설정 칼럼

처음 2주는 작게

처음부터 키워드를 수백 개 넣고 큰 예산을 걸면 어디서 돈이 새는지 알기 어렵습니다. 손님이 실제로 칠 만한 검색어 10~20개, 감당할 수 있는 하루 예산으로 시작해서 2주 정도 클릭과 문의를 본 뒤에 늘리는 편이 안전합니다. 어떤 검색어를 고를지는 키워드 고르는 법 칼럼을 참고하세요.

혼자 하기 어렵다면 대행을 맡길 수도 있지만, 위 순서를 한 번 알고 나면 대행사의 보고서를 읽고 판단하기가 훨씬 쉬워집니다.
