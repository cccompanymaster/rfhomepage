홈페이지 유지보수 범위, 어디까지가 유지보수일까

홈페이지 유지보수에 보통 무엇이 포함되고 무엇이 별도 비용인지 현실적으로 정리했습니다. 월 계약과 건별 처리의 선택 기준, 계약 전에 물어볼 질문까지 함께 다룹니다.

이 글의 순서

  1. 보통 유지보수에 포함되는 것
  2. 보통 별도 비용인 것
  3. 월 계약과 건별 처리의 선택
  4. 계약 전 확인할 질문
  5. 정리

홈페이지 유지보수를 두고 고객과 업체의 기대가 어긋나는 일이 잦습니다. 고객은 “수정을 다 해주는 것”으로, 업체는 “사이트가 죽지 않게 관리하는 것”으로 이해하는 경우가 많기 때문입니다. 어느 쪽이 틀렸다기보다 범위를 미리 정하지 않은 것이 문제입니다. 유지보수의 현실적인 범위를 정리해 보겠습니다.

보통 유지보수에 포함되는 것

  • 서버·호스팅 상태 관리와 장애 발생 시 대응
  • 솔루션, 플러그인 등 소프트웨어 보안 업데이트
  • 정기 백업과 문제 발생 시 복구 지원
  • SSL 인증서 갱신 등 보안 기본 관리
  • 텍스트, 이미지 교체 같은 경미한 수정

보통 별도 비용인 것

  • 새 페이지 추가, 메뉴 구조 변경
  • 디자인 리뉴얼이나 레이아웃 변경
  • 새 기능 개발(예약, 게시판, 다국어 추가 등)
  • 콘텐츠 기획과 원고 작성, 사진 촬영
  • 검색 최적화, 광고 운영 같은 마케팅 업무

경계선에 있는 요청도 많습니다. 예를 들어 “배너 이미지 하나 교체”는 포함이지만 “메인 페이지 구성 변경”은 별도인 식입니다. 이 경계를 계약할 때 구체적인 예시로 정해 두면 나중에 다툴 일이 크게 줄어듭니다.

월 계약과 건별 처리의 선택

수정 요청이 매달 꾸준히 있다면 월 계약이, 1년에 몇 번 수준이라면 건별 처리가 경제적입니다. 월 계약이라면 월 처리 한도(시간 또는 건수)와 미사용분 이월 여부를 확인하세요. 거의 방치되는 홈페이지에 월 비용을 계속 내는 것도, 필요할 때마다 견적을 받는 번거로움도 정답은 아니므로, 지난 1년간 내가 실제로 수정을 몇 번 요청했는지 세어 보고 결정하면 현실적입니다.

계약 전 확인할 질문

  • 월 수정 한도는 몇 건 또는 몇 시간인가
  • 요청 후 처리까지 걸리는 통상 시간은 얼마인가
  • 장애 발생 시 대응 시간 기준이 있는가
  • 백업 주기와 보관 기간은 어떻게 되는가
  • 해지 시 데이터와 계정은 어떻게 인계되는가

정리

유지보수의 기본은 사이트를 안정적으로 돌아가게 하는 것이고, 기능 추가와 리뉴얼은 별도 영역입니다.

포함 범위를 구체적인 예시와 함께 계약서에 적어 두는 것이 분쟁 예방의 핵심입니다.

NOAH는 1년 무제한 텍스트 수정을 기본 제공하고, 유지보수는 월 3만원 또는 연 15만원 옵션으로 운영합니다.
