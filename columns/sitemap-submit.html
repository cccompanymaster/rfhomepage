SEO·검색노출

사이트맵 제출 방법, 네이버·구글에 한 번에 알리기

사이트맵(sitemap.xml)이 무엇인지부터 만드는 방법, 네이버 서치어드바이저와 구글 서치콘솔에 제출하는 절차, 제출 후 확인 포인트까지 순서대로 정리한 실무 가이드입니다.

  4. 제출 후 확인과 관리
  5. 제출하고 나서 할 일

사이트맵(sitemap.xml)은 내 홈페이지에 어떤 페이지들이 있는지 검색엔진에 알려주는 목록 파일입니다. 검색로봇이 링크를 따라다니며 페이지를 발견하기도 합니다. 다만 사이트맵이 있으면 새 페이지나 깊숙한 페이지까지 빠뜨리지 않고 수집하도록 도울 수 있습니다. 특히 페이지가 많거나 새로 연 사이트라면 제출해 두는 것이 좋습니다.

사이트맵 만드는 방법

  1. 제작 도구·플랫폼 기능 확인: 워드프레스(SEO 플러그인), 아임웹·카페24 등 대부분의 플랫폼은 사이트맵을 자동 생성합니다. 보통 내주소/sitemap.xml 로 접속해 보면 존재 여부를 알 수 있습니다.
  2. 자동 생성이 없다면: 온라인 사이트맵 생성 서비스에 주소를 넣어 XML 파일을 만들고, 서버 최상위 폴더에 업로드합니다.
  3. 직접 작성: 페이지가 몇 개 안 되면 <urlset> 안에 페이지별 <url><loc>주소</loc></url> 항목을 나열한 XML 파일을 만들어도 됩니다.

구글 서치콘솔에 제출하기

  1. 서치콘솔에 로그인해 내 사이트 속성을 선택합니다.
  2. 사이트맵 메뉴를 찾아 들어갑니다.
  3. 입력란에 sitemap.xml 경로를 입력하고 제출합니다.
  4. 상태가 "성공"으로 표시되는지, 발견된 URL 수가 실제 페이지 수와 비슷한지 확인합니다.

네이버 서치어드바이저에 제출하기

  1. 서치어드바이저 웹마스터 도구에서 내 사이트를 선택합니다.
  2. 사이트맵 제출 메뉴를 찾아 sitemap.xml 주소를 입력하고 제출합니다.
  3. 블로그형 콘텐츠가 있다면 RSS 제출 메뉴에 RSS 주소도 함께 제출하면 좋습니다.

두 서비스 모두 메뉴 위치가 개편되곤 합니다. 사이트맵이라는 이름의 메뉴를 현재 화면에서 찾는 방식으로 접근하세요.

제출 후 확인과 관리

제출 직후 모든 페이지가 색인되는 것은 아니며, 처리에 며칠 이상 걸릴 수 있습니다. 오류가 표시되면 사이트맵 주소 오타, 접속 불가(서버 문제), XML 형식 오류가 흔한 원인입니다. 페이지를 추가·삭제했을 때 자동 생성 사이트맵은 스스로 갱신되지만 수동 작성 파일은 직접 업데이트해야 합니다. robots.txt 파일에 Sitemap: https://내주소/sitemap.xml 한 줄을 넣어 두면 검색로봇이 사이트맵을 더 쉽게 찾습니다.

제출하고 나서 할 일

사이트맵은 검색엔진에 전달하는 페이지 목록입니다. 플랫폼이 자동 생성하는지부터 확인하고, 구글 서치콘솔과 네이버 서치어드바이저 양쪽에 제출하세요. 그다음은 오류 여부와 색인 현황을 살피고 페이지가 바뀔 때마다 갱신하는 일입니다. NOAH 제작 패키지에는 사이트맵 생성이 기본 포함되어 있어 제출만 하면 되는 상태로 사이트가 나갑니다.
