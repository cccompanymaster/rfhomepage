구글 애널리틱스(GA4) 설치, 개념부터 확인까지

구글 애널리틱스 GA4 설치 과정을 처음 하는 분 눈높이로 정리했습니다. 계정·속성 구조, 추적 코드 넣는 방법, 설치 확인과 초기 설정 포인트까지 안내합니다.

구글 애널리틱스(GA4)는 홈페이지에 누가, 어디서, 어떻게 들어왔는지 보여주는 무료 분석 도구입니다. 설치라고 하면 어렵게 들리지만, 실제로는 “계정을 만들고, 코드 한 조각을 홈페이지에 붙여 넣는 일”입니다. 개념만 잡으면 외주 없이도 진행할 수 있습니다.

GA4의 기본 구조 이해하기

GA4는 계정 → 속성 → 데이터 스트림의 구조로 되어 있습니다. 계정은 회사, 속성은 홈페이지 하나, 데이터 스트림은 데이터가 들어오는 통로라고 이해하면 됩니다. 홈페이지가 하나라면 계정 하나에 속성 하나, 웹 데이터 스트림 하나면 충분합니다. 스트림을 만들면 G-로 시작하는 측정 ID가 발급됩니다.

설치의 큰 흐름

  1. 구글 계정으로 애널리틱스 공식 페이지에 접속해 계정과 속성을 만듭니다.
  2. 웹 데이터 스트림을 만들고 홈페이지 주소를 입력해 측정 ID를 받습니다.
  3. 안내되는 추적 코드(태그)를 홈페이지 모든 페이지의 head 영역에 넣습니다.

화면 구성은 수시로 바뀌므로 버튼 위치보다 이 흐름을 기억하세요. 워드프레스나 아임웹 같은 빌더는 코드 삽입 메뉴나 연동 기능을 제공하는 경우가 많아 코드를 직접 만지지 않고도 넣을 수 있습니다.

구글 태그 매니저(GTM)와 함께 쓰기

버튼 클릭, 전화 터치 같은 세부 행동까지 추적하려면 구글 태그 매니저를 함께 쓰는 방법이 있습니다. GTM 코드를 한 번 심어두면 이후 태그 추가·수정을 홈페이지 코드를 건드리지 않고 GTM 화면에서 처리할 수 있어 장기적으로 편리합니다. 처음에는 GA4만 설치하고, 필요해질 때 GTM을 더해도 늦지 않습니다.

설치 후 꼭 확인할 것

  • 실시간 보고서로 내 접속이 잡히는지 확인합니다. 데이터가 보고서에 온전히 쌓이기까지는 시간이 걸릴 수 있습니다.
  • 구글 서치 콘솔과 연결해 검색 유입 데이터를 함께 봅니다.
  • 상담 신청, 전화 클릭 등 중요한 행동을 이벤트(전환)로 지정해 둡니다.
  • 내부 직원 접속이 섞이지 않도록 필터링 옵션을 검토합니다.

정리

  • GA4 설치는 계정·속성·스트림 생성 후 추적 코드를 head에 넣는 작업입니다.
  • 실시간 보고서로 설치 여부를 확인하고 서치 콘솔 연결까지 해두면 좋습니다.
  • 세부 행동 추적이 필요해지면 GTM을 더하는 순서를 추천합니다.

직접 하기 부담스럽다면 NOAH 패키지를 참고하세요. GA·GTM 설치 지원이 포함되어 있어 오픈과 동시에 데이터 측정을 시작할 수 있습니다.
