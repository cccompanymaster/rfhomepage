홈페이지 보안이라고 하면 전문 영역처럼 들리지만, 실제 사고의 상당수는 기본적인 관리 소홀에서 시작됩니다. 오래된 소프트웨어, 단순한 비밀번호, 방치된 계정 같은 것들입니다. 반대로 말하면 기본만 지켜도 위험이 크게 줄어든다는 뜻입니다. 전문 지식 없이 사장님이 직접 확인할 수 있는 항목을 정리했습니다.

SSL 인증서: 자물쇠부터 확인

브라우저 주소창에 자물쇠 표시가 있고 주소가 https로 시작하는지 확인하세요. SSL이 없으면 방문자 브라우저에 “안전하지 않음” 경고가 뜨고 검색 노출에도 불리합니다. 인증서는 유효기간이 있어 갱신을 놓치면 어느 날 갑자기 사이트 전체에 경고가 뜨므로, 갱신이 자동인지 수동인지, 관리 주체가 호스팅사인지 제작 업체인지 알아 두어야 합니다.

소프트웨어 업데이트

홈페이지 솔루션, 플러그인, 테마는 보안 취약점이 발견될 때마다 업데이트로 보완됩니다. 오래 방치된 구버전은 알려진 취약점이 공개되어 있는 상태라 자동화된 공격에 쉽게 노출됩니다. 쓰지 않는 플러그인은 비활성화가 아니라 삭제하는 것이 좋고, 업데이트 전 백업을 먼저 하고 적용하는 순서만 지키면 부담 없이 관리할 수 있습니다.

비밀번호와 계정 관리

  • 관리자 비밀번호는 다른 서비스와 다르게, 길고 복잡하게 설정
  • 기본 아이디(admin 등)를 그대로 쓰지 않기
  • 2단계 인증이 지원되면 반드시 켜기
  • 퇴사자, 계약이 끝난 업체의 계정은 즉시 삭제하거나 비밀번호 변경
  • 계정을 여럿이 공유하지 말고 사람별로 발급

관리자 접근 관리

관리자 페이지 주소가 기본값 그대로면 자동화된 공격의 표적이 되기 쉽습니다. 가능하면 주소를 바꾸고, 접속 기록을 가끔 확인해 낯선 시간대나 낯선 위치의 접근이 없는지 살펴보세요. 관리 권한은 꼭 필요한 사람에게 필요한 만큼만 부여하는 것이 원칙입니다.

분기별 점검 루틴

  • https 접속과 인증서 만료일 확인
  • 솔루션·플러그인 업데이트 적용(백업 후)
  • 관리자 계정 목록 정리와 접속 기록 확인
  • 백업이 실제로 쌓이고 있는지, 복구 가능한지 확인

정리

보안의 기본은 SSL, 업데이트, 비밀번호, 관리자 접근 네 가지 관리입니다.

분기에 한 번 점검 루틴만 돌려도 흔한 사고의 대부분은 예방할 수 있습니다.
