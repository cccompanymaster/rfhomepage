SSL 인증서 설치, 자물쇠 표시 만드는 법

SSL 인증서가 왜 필요한지, 무료와 유료의 차이, 설치 방법과 설치 후 확인 사항까지 초보자 눈높이로 설명합니다. https 적용을 위한 기본 가이드입니다.

내 홈페이지에 접속했더니 '주의 요함'이나 '안전하지 않음'이라는 문구가 떠서 놀라셨나요? 십중팔구 SSL 인증서가 없거나 만료된 경우입니다. 이 글에서 SSL이 무엇이고 왜 필요한지, 어떻게 설치하는지를 차근차근 설명합니다.

SSL 인증서란 무엇인가

SSL 인증서는 방문자와 홈페이지 사이에 오가는 정보를 암호화해 주는 장치입니다. 설치하면 주소가 http에서 https로 바뀌고 브라우저 주소창에 자물쇠 표시가 나타납니다.

문의 양식으로 이름과 연락처를 받는 홈페이지라면 사실상 필수입니다. 암호화가 없으면 전송 중인 정보가 노출될 위험이 있기 때문입니다.

없으면 어떤 일이 생기나

크롬 같은 주요 브라우저는 SSL이 없는 사이트에 경고 문구를 표시합니다. 고객 입장에서는 '이 사이트 이상한가?' 하는 인상을 받고 이탈하기 쉽습니다.

검색엔진도 https 여부를 사이트 평가 요소 중 하나로 참고한다고 밝혀 왔습니다. 노출 순위를 결정짓는 전부는 아니지만, 갖춰서 손해 볼 일은 없습니다.

무료와 유료의 차이

Let's Encrypt 같은 무료 인증서는 암호화 수준 자체는 일반적인 용도에 충분하며, 90일마다 자동 갱신하는 방식으로 운영됩니다. 요즘 호스팅 업체 대부분이 무료 인증서 자동 적용을 지원합니다.

유료 인증서는 발급 시 기업 실재성 검증을 거치는 상품 등이 있고 보증 조건이 붙기도 합니다. 소개형 홈페이지라면 무료로 시작해도 무리가 없는 경우가 많습니다.

설치는 어떻게 하나

  1. 호스팅 관리 페이지에서 SSL 메뉴를 찾는다
  2. 무료 인증서 발급 또는 보유 인증서 설치를 선택한다
  3. 적용 후 https 주소로 접속해 자물쇠 표시를 확인한다
  4. http 접속 시 https로 자동 이동(리디렉션)되는지 확인한다

클라우드플레어 같은 서비스를 이용해 적용하는 방법도 있습니다. 호스팅마다 화면이 달라, 어렵다면 호스팅 고객센터나 제작사에 요청하는 것이 빠릅니다.

설치 후 확인할 것

설치했는데도 자물쇠가 안 뜨는 경우가 있습니다. 페이지 안의 이미지가 http 주소로 불려오는 '혼합 콘텐츠'가 흔한 원인입니다. 또 인증서에는 유효기간이 있으므로 자동 갱신이 설정돼 있는지 확인해 두세요.

정리

첫째, SSL은 https와 자물쇠 표시를 만드는 암호화 장치로, 문의 양식이 있다면 필수입니다. 둘째, 무료 인증서로도 일반 홈페이지에는 충분한 경우가 많습니다. 셋째, 설치 후엔 리디렉션과 자동 갱신을 꼭 확인하세요. NOAH 패키지에도 도메인 연결과 함께 SSL 적용 안내가 포함되어 있으니 혼자 막힌다면 이런 도움을 받는 것도 방법입니다.
